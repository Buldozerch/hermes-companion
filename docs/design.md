# Дизайн Hermes Companion

Плотный инженерный инструмент с плоскими монохромными поверхностями. Это постоянное направление для всех экранов, состояний и новых компонентов.

## Палитра

| Роль | Значение |
| --- | --- |
| Основной фон | `#09090b` |
| Панели и диалоги | `#121214` |
| Вторичная поверхность | `#18181b` |
| Основной текст и акцент | `#f4f4f5` |
| Читаемый вторичный текст | `#a1a1aa` |
| Приглушённые вспомогательные элементы | `#71717a` |
| Границы | `#27272a` |
| Границы при наведении | `#3f3f46` |

Статусы, ошибки и подтверждения используют ту же палитру. Их смысл передают подпись, пиктограмма и характер границы. Синий, фиолетовый, зелёный, красный и прочие цветные акценты не добавлять. Вторичный текст должен оставаться достаточно контрастным; `#71717a` предназначен для вспомогательной графики, а не мелких инструкций.

## Типографика и плотность

- Системный гротеск для текста, заголовков и объяснений.
- Локальный JetBrains Mono для адресов, параметров, цифр, статусов, меток и кнопок.
- Общий масштаб интерфейса — 120%: базовый размер корня 19.2 px, размеры текста, отступов, иконок и контролов заданы в rem. Границы остаются 1 px, скругления — 2–4 px.
- Основной заголовок около 28–29 px, заголовки панелей около 19–22 px. Без рекламных заголовков на половину экрана.
- Метки, статусы и кнопки в uppercase с небольшим трекингом. Введённые значения сохраняют исходный регистр.
- Элементы управления преимущественно высотой 34–38 px. Внутренние отступы панелей примерно 14–24 px. Точки адаптации увеличены с учётом масштаба.
- Настройки группируются по смыслу, параметры располагаются в плотных строках и таблицах. Пустые области не заполняются выдуманными логами, метриками или статусами.

## Геометрия и реакции

- Скругления 2–4 px, абсолютный максимум 6 px. Переключатели тоже прямоугольные.
- Сплошные границы 1 px. Без мягких теней, градиентов, свечения, blur, glassmorphism и декоративных орбит.
- Hover: изменение цвета границы/поверхности либо белая инверсия. Переход 100 ms ease-out.
- Клавиатурный фокус: чёткая белая обводка 1 px. Без размытого кольца.
- Диалоги появляются без масштабирования и скольжения; фон затемняется без blur.
- Автоматические анимации страниц отключены. Индикатор ожидания используется только во время операции. Reduced motion соблюдается.

## Реализация

Токены и компоновка находятся в `frontend/styles.css`, варианты стандартных элементов — в `frontend/components/ui/`. Менять саму систему и варианты компонентов, а не дописывать поверх неё случайные локальные цвета и тени. Знак приложения и установочные иконки тоже монохромные.
